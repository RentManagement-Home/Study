Bug Report + Updated Index.html & Code.gs

Copy or download both updated files directly for your Google Apps Script project.

1. Cross-Midnight Schedule Sorting & Gap Break Bug: Slots crossing midnight or ending after midnight (e.g., 23:00–01:00) broke gap-break calculation and sorting. Fixed timeline sorting and gap detection to handle overnight wraps cleanly.
2. Midnight Rollover Split-Time Bug in flushTimersToNow: If a timer was running across 00:00 midnight (or while the tab was backgrounded overnight), all elapsed seconds were credited to the new day instead of splitting at midnight. Fixed so pre-midnight seconds go to yesterday (and auto-archive yesterday) and post-midnight seconds go to today.
3. Overnight Break Hold Overflow Bug: If a break hold remained active across midnight, all held seconds were credited to the new day and deducted from the new day's slot. Fixed by auto-releasing break holds at the midnight rollover boundary onto the day they started.
4. Stale Runtime Timer State Across Days: loadTimerRuntime() restored activeRoutineSlotId, routineLastTickMs, and manualLastTickMs from previous days without checking if the saved timestamp belonged to an earlier date, causing huge phantom hours on load. Added day-boundary reconciliation on boot.
5. Routine Auto-Pause Clock Drift & Midnight End Calculation Bug: In flushTimersToNow, getSlotEndMsForNow(new Date(routineLastTickMs), rs) recomputed remaining seconds from a past timestamp and could miss the auto-pause boundary or add 24 hours. Replaced with an exact wall-clock target timestamp routineSchedEndMs stored when the routine slot starts.
6. Double-Counting Routine Progress in Stats & Archive: When a slot was unchecked after accumulating loggedHours, or when slot duration was adjusted via break-hold deduction, loggedHours wasn't synced continuously during live ticks unless paused. Now loggedHours is updated continuously on every flush and auto-archived accurately.
7. Heatmap & Streak Ignoring Live Unarchived Study Time: The 14-day Consistency Heatmap only read appState.archives[key]?.percentage, showing 0% for days where the user studied via Manual/Focus/Routine timers without clicking "Archive Day". Fixed heatmap to compute live completion % from both archives and tracked study duration.
8. applyRemoteState Overwriting Active Local Study Seconds: When pulling from Google Apps Script every 45 seconds, if another device had a slightly newer updatedAt, local in-progress dailyStudyLogs were overwritten. Added client-side & server-side non-decreasing merge for dailyStudyLogs, dailyLogs, archives, and reflections.
9. Custom Reminder Re-Firing After Page Reload Within Same Minute: firedCustomKeys and firedPreShiftKeys lived only in memory, so refreshing the page during the reminder minute or 10-min pre-shift window re-triggered all alerts. Persisted today's fired alert keys in sessionStorage.
10. Editing Routine Plan Metadata Didn't Update routineHistory: Editing a saved plan's title/name/subtitle in the Plans Manager updated appState.profiles[id] but left existing routineHistory entries pointing to that profileId with stale titles. Fixed savePlanForm to sync linked routineHistory entries.
11. Google Apps Script (Code.gs) File Case & Concurrent Device Merge: Added fallback for both Index.html and index.html in doGet(?ui=1), safe handling when payload.state is passed as string or object, text formatting on percentage columns so Sheets doesn't convert 85% to 0.85, and server-side mergeRemoteAndIncomingStates_ so multi-device sync never loses study time.
